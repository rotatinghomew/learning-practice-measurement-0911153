# 练习记录多源误差下学习投入与成效关系的校正：业务资料契约

learners 是分析对象，observations 每次对应 learner、occasion、channel 和 minutes；minutes=null 为未记录，零表示明确未练习。household 标记可能共用代填者；audits 包含入选概率、设备观测和人工时间区间，均非真值。score 为后续测验结果，baseline_score 在练习前取得。不同渠道的共同偏差不可仅靠增加重复次数识别。

所有示例记录由本地确定性生成，不含真实居民、客户或学校个人资料。`revision` 指向整包不可变资料，`synthetic=true` 只说明资料性质，不声明统计结论。

## 当前产品边界

现有分析 `repeatability` 已可通过资料目录服务、分析服务和结果回读完整运行；它只给已观察记录的业务核对，不实现 `dose_response`。新分析需要与当前核对功能并存，统计方法、模型分解和诊断组织由实现者根据证据选择。

新分析的最小产品交付是可保存的结构化分析结果，包含目标人群/估计对象、所用资料及排除原因、估计或可识别范围、适用条件、诊断和业务解释；无法估计时给原因而不是伪造数值。`options` 应允许调用者保存并重放题面涉及的假设或情景，具体字段可随实现补充文档。默认调用用资料能够支持的基本情景，不能把未声明的强假设隐藏进默认值。数值容差、随机种子和蒙特卡洛精度要可复查。

## 已有业务投影视图

`app/measurements.py` 的 `measurement_profile` 为当前核对分析生成 `source_profile`，保留此项目的分析单位、重复观测和资料组织。这些已观察资料的投影不是新分析结果；可复用其数据关系，但不能把描述统计当成推断。修改现有资料处理时要保留 `tests/test_context.py` 的业务不变量。
